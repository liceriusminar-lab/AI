## Что это такое

Sylviette AI — это десктопный чат-ассистент с персонажем по имени **Сильфиетта**. Она работает на базе локальной языковой модели через [Ollama](https://ollama.com/) и умеет не только отвечать на вопросы, но и управлять твоим компьютером напрямую из чата.

**Ключевые возможности:**
- 💬 Чат с историей, темами, поиском по разговорам
- 🖥️ Управление системой — запуск программ, файлы, команды в терминале
- 🎮 Макросы — одна фраза запускает цепочку действий (например «я дома» → Steam + Spotify)
- 🌐 Веб-поиск через DuckDuckGo прямо в чате
- 📅 Встроенный календарь с напоминаниями
- 🎤 Голосовой ввод
- 🧩 Система плагинов (погода, калькулятор и свои)
- 🎨 Темы оформления, полностью настраиваемый интерфейс

## Быстрый старт

```bash
# 1. Клонируй репозиторий
git clone https://github.com/liceriusminar-lab/AI.git
cd AI

# 2. Создай виртуальное окружение и установи зависимости
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 3. Установи и запусти Ollama
# https://ollama.com/download
ollama pull dolphin3:8b   # основная модель

# 4. Запусти Сильфиетту
python3 main.py
```

> При первом запуске `main.py` автоматически стартует Ollama и inference-сервер в фоне.

## Что можно смело менять самому

### ✅ `macros.py` — Макросы
Самый простой файл для редактирования. Добавляй свои сценарии по образцу:

```python
{
    "name": "мой_макрос",
    "description": "Что он делает",
    "triggers": ["фраза 1", "скажи мне это", "another phrase"],
    "response": "Ответ Сильфиетты в чате",
    "actions": [
        {"type": "open_url",   "url": "https://youtube.com"},
        {"type": "launch_app", "cmd": "discord"},
        {"type": "delay",      "seconds": 2},
        {"type": "notify",     "title": "Готово", "message": "Всё запущено"},
        {"type": "shell",      "cmd": "любая_команда_bash"},
    ]
}
```

Типы действий: `open_url`, `launch_app`, `shell`, `delay`, `notify`, `steam_switch_and_launch`, `steam_game`

### ✅ `personality.py` — Характер и стиль ответов
Меняй `SYSTEM_PROMPT` чтобы изменить как ассистент общается, как обращается к тебе, какой у него стиль.

```python
# personality.py
SYSTEM_PROMPT = """Ты — ..."""
ASSISTANT_NAME = "Сильфиетта"   # Имя в интерфейсе
```

### ✅ `plugins/` — Плагины
Создай папку `plugins/мой_плагин/` с двумя файлами:

**`plugin.json`:**
```json
{
  "name": "Мой плагин",
  "description": "Что он делает",
  "enabled": true,
  "triggers": ["слово которое его активирует"]
}
```

**`main.py`:**
```python
def run(query: str, context: dict) -> str:
    return "Ответ плагина"
```

### ✅ `ui/theme_presets.py` — Темы оформления
Добавляй свои темы по образцу существующих. Ключи: `bg`, `sidebar`, `accent`, `accent2`, `font_size`, `bubble_radius`.

### ✅ `config.py` — Пути и URLs
Порты серверов, путь к иконке, путь к истории чатов.

### ✅ `profiles.py` — Профили режимов
Каждый профиль — это дополнительный промпт который меняет стиль ответов. Редактируй существующие или добавляй новые прямо в `DEFAULT_PROFILES`.

## Что лучше не трогать

### ⚠️ `ollama_worker.py`
Центральный нерв приложения. Управляет потоком общения с моделью, стримингом токенов, выполнением системных команд. Редактировать только если понимаешь что делаешь. **Перед любыми изменениями делай бэкап.**

### ⚠️ `ui/main_window.py`
Очень большой файл (~900 строк), вся логика UI в одном месте. Случайная опечатка может сломать весь интерфейс. Изменяй точечно, тестируй после каждого правки.

### ⚠️ `chat_manager.py`
Отвечает за сохранность всей истории чатов. Баг здесь = потеря разговоров. Не трогай без крайней необходимости.

### ⚠️ `sylviette_ai/transformer.py` и `sylviette_ai/train.py`
Архитектура и обучение собственной нейросети. Изменения требуют понимания PyTorch и трансформерных моделей. Неверный параметр → потраченные часы обучения.

### ⚠️ `encryption.py`
Шифрование истории. Изменение алгоритма или ключа без миграции = история чатов станет нечитаемой.

## Настройка модели

По умолчанию используется `dolphin3:8b` — хорошая модель без цензуры для личного использования.

Поменять модель:
```bash
ollama pull llama3.1:8b       # или любую другую
```

В `sylviette_ai/inference.py` измени:
```python
OLLAMA_MODEL = "llama3.1:8b"  # ← новая модель
```

Или выбери прямо в интерфейсе через выпадающий список в сайдбаре.

## Макросы — подробнее

Макросы — это сценарии которые запускаются по ключевой фразе. Например:

```
Ты → «я дома»
Сильфиетта → «С возвращением! Запускаю всё ✦»
             [фоново: открывает Spotify в браузере,
              переключает Steam на основной аккаунт,
              ждёт 14 сек пока Steam загрузится,
              запускает War Thunder]
```

**Проверить что Steam аккаунты найдены:**
```bash
cd ~/ai-assistant
python3 macros_engine.py
```

**Узнать App ID игры в Steam:**  
Зайди на страницу игры в Steam Store — в URL будет `/app/XXXXXX/` — это и есть App ID.

## Автозапуск при входе в систему

```bash
# Скопируй сервис
sudo cp start_sylviette.sh /usr/local/bin/sylviette
sudo chmod +x /usr/local/bin/sylviette

# Добавь в автозапуск KDE:
# Параметры системы → Автозапуск → Добавить → /usr/local/bin/sylviette
```

Или через systemd — пример сервиса в `start_sylviette_service.sh`.

## Обучение собственной модели (опционально)

Если хочешь использовать **собственную** модель вместо Ollama:

```bash
# Подготовить датасет с диалогами
python -m sylviette_ai.prepare_data --chat

# Предобучение на текстах
bash start_training.sh  # выбери 1

# Файнтюнинг на диалогах
bash start_training.sh  # выбери 2

# Запуск своей модели
python -m sylviette_ai.inference --checkpoint checkpoints/sylviette-pretrain/latest.pt
```

Требует RTX 4050 6GB или лучше. Обучение ~350M параметров займёт несколько часов.
